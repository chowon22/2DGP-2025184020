# PRD — 소닉 애니메이션 뷰어

> 원본 요구사항: [PRE-PRD.md](PRE-PRD.md)
> 브랜치: `lec09-sonic-viewer`

## 1. 개요

`sonic-sprite.png` 스프라이트 시트에 들어 있는 소닉의 모든 동작을 차례로 재생하는 pico2d 뷰어를 만든다.
동작마다 5회 반복 재생하고, 1초 쉰 뒤 다음 동작으로 넘어간다. 마지막 동작이 끝나면 처음부터 무한 반복한다.
달리기 동작(달리기·빠른 달리기·슈퍼 필아웃)과 공 모양으로 구르는 동작(스핀·볼 구르기)은 재생하는 동안 캐릭터가 화면을 가로질러 실제로 이동한다.

## 2. 기술 제약

| 항목       | 내용                                                                                     |
| ---------- | ---------------------------------------------------------------------------------------- |
| 언어       | Python 3                                                                                 |
| 라이브러리 | pico2d (표준 라이브러리 외 다른 의존성 없음)                                             |
| 파일       | `Labs/LEC09/sonic_animation_viewer.py` **단일 파일**                             |
| 리소스     | `Labs/LEC09/sonic-sprite.png` (399 × 525, RGBA, 배경 투명)                            |
| 실행 위치  | `Labs/LEC09` 폴더에서 `python sonic_animation_viewer.py` (이미지를 상대 경로로 읽음) |

## 3. 스프라이트 시트 분석

시트는 **균일한 격자가 아니다.** 프레임마다 너비·높이·간격이 다르므로 `frame * width` 방식의 계산은 쓸 수 없고,
프레임별 사각형 좌표를 코드에 표로 넣어야 한다.

아래 좌표는 PNG의 투명하지 않은 픽셀을 연결 영역으로 분석해서 구했다.
`left`, `bottom`은 pico2d `clip_draw` 기준(이미지 **왼쪽 아래**가 원점)이다.
이미지 위쪽 기준 y에서 바꾸는 식은 `bottom = 525 - (top + h)`.

| ID  | 요구사항                                                                                                        |
| --- | --------------------------------------------------------------------------------------------------------------- |
| F-1 | 3.1의 17개 동작을 1번부터 17번까지 순서대로 재생한다.                                                           |

| F-11 | 모든 동작은 화면 중앙에서 시작한다. 쉬는 1초 동안에는 이동하지 않는다.                                          |

### 4.1 화면·확대 기준

- 캔버스: 800 × 600
- 확대 배율: **8배** (상수 `SCALE`). 가장 큰 프레임(약 40 × 45)이 약 320 × 360으로 그려져 화면 안에 여유 있게 들어간다.
- 가로 위치: 동작 시작 때 캔버스 중앙 (x = 400). 이동 동작은 여기서 출발한다.
- 바닥선: 화면 아래에서 약 100px. 그리는 y = `바닥선 + h * SCALE / 2`
- 배경: pico2d 기본 배경(검은색 계열) 그대로 사용. 확대 후 도트가 뭉개지면 배경색과 대비만 확인한다.

### 4.2 타이밍 기준

| 상수             | 값    | 의미                                         |
| ---------------- | ----- | -------------------------------------------- |
| `FRAME_TIME`   | 0.1초 | 프레임 하나를 보여 주는 시간 (초당 10프레임) |
| `REPEAT_COUNT` | 5     | 동작별 반복 횟수                             |
| `PAUSE_TIME`   | 1.0초 | 동작 사이 쉬는 시간                          |

`delay()` 안에서 이벤트 처리가 멈추지 않도록, 쉬는 1초도 `FRAME_TIME` 단위로 나눠 루프를 돌면서 이벤트를 계속 처리한다.

### 4.3 이동 기준

- 동작마다 이동 속도를 둔다 (3.1 표). 코드에서는 `actions`와 같은 순서의 `speeds` 리스트로 둔다.
- 매 프레임 `x += speeds[action]`. 소닉 그림이 오른쪽을 보고 있으므로 오른쪽으로만 이동한다 (좌우 반전 없음).
- `x`가 `CANVAS_WIDTH + WRAP_MARGIN`을 넘으면 `x = -WRAP_MARGIN`으로 옮겨 왼쪽에서 다시 들어오게 한다.
  `WRAP_MARGIN = 200`은 가장 넓은 프레임(40px × 8배 = 320px)의 절반보다 커서, 그림이 화면 끝에서 갑자기 사라지거나 나타나지 않는다.
- 다음 동작으로 넘어갈 때 `x`를 캔버스 중앙으로 되돌린다.

## 5. 비기능 요구사항

- 코드 스타일은 기존 랩 코드(`LEC08_Animation/character_runs.py`, `LEC10_HandlingInputs/character_runs_esc.py`)를 따른다: `from pico2d import *`, 모듈 수준의 단순한 루프, `handle_events()` 함수.
- 클래스·외부 파일·설정 파일 없이 한 파일 안에서 끝낸다.
- 프레임 좌표는 동작별 리스트로 묶어 코드 위쪽에 둔다. 동작을 더하거나 빼려면 그 리스트(와 `speeds`)만 고치면 되게 한다.

## 7. 완료 기준 (인수 테스트)

1. `Labs/LEC09`에서 `python sonic_animation_viewer.py`를 실행하면 오류 없이 창이 뜬다.
2. 17개 동작이 순서대로, 각 5회씩 재생된다.
3. 동작 사이마다 약 1초 멈춘다.
4. 17번 동작 뒤에 1번 동작이 다시 시작되고, 이것이 계속 반복된다.
5. 캐릭터가 화면 중앙에 크게 보이고, 프레임이 바뀌어도 바닥선이 흔들리지 않는다.
6. 어떤 프레임에도 옆 프레임 조각이나 글자가 섞여 보이지 않는다.
7. ESC 또는 창 닫기로 언제든 바로 끝난다 (쉬는 중 포함).
8. 저장소에 `sonic_animation_viewer.py` 외에 새 파이썬 파일이 없다.
9. 이동 동작(4번 달리기, 6번 스핀, 7번 볼 구르기, 9번 빠른 달리기, 11번 슈퍼 필아웃)은 중앙에서 출발해 오른쪽으로 이동하고, 화면을 벗어나면 왼쪽에서 다시 들어온다.
10. 나머지 제자리 동작(1~3, 5, 8, 10, 12~17번)은 화면 중앙에 머문다.
11. 한 동작 안에 다른 동작의 프레임이 섞여 재생되지 않는다.

## 8. 범위 밖

- 좌우 반전(왼쪽으로 이동), 세로 이동(점프), 배경 이미지
- 슈퍼 소닉·샐리 등 다른 캐릭터 이미지
